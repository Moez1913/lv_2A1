TypeScript Fundamentals Assignment

Overview

This assignment demonstrates my understanding of core TypeScript concepts through practical coding exercises. It covers functions, union types, optional parameters, tuples, generics, interfaces, utility types, object-oriented programming (OOP), and asynchronous programming.

Concepts Covered

Optional Parameters & Default Logic

Implemented a multiplication function with an optional parameter.

Handled different multiplier conditions.

Union Types & Type Narrowing

Used union types (string | number | boolean).

Applied typeof checks to handle different input types.

Tuples & Readonly

Created a readonly tuple for geographic coordinates.

Used tuple destructuring to access values.

Generics

Implemented a generic function to concatenate multiple arrays.

Used generics to maintain type safety and reusability.

Interfaces

Defined a Course interface.

Implemented filtering logic to find popular and published courses.

Keyof & Generic Constraints

Used keyof and extends to create a reusable pluckValues function.

Extracted specific property values from objects with type safety.

Object-Oriented Programming (OOP)

Implemented classes using constructors and methods.

Practiced inheritance with extends and super().

Used protected and private access modifiers.

Asynchronous Programming

Implemented a Promise-based asynchronous function.

Used resolve, reject, and setTimeout to handle asynchronous operations.
